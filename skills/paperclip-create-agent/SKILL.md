# Skill: paperclip-create-agent

## Objective
Hire a new agent and assign them to the company hierarchy.

## Instructions
Use the `hire_agent.sh` script to call the Paperclip API.
The script requires:
- `PAPERCLIP_API_KEY`
- `PAPERCLIP_COMPANY_ID`
- `PAPERCLIP_CEO_ID` (as the reportsTo)

## Tools
- `hire_agent.sh`: Bash script to execute the hire.
